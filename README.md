# HIRE-U | Portafolio del Proyecto Integrador

HIRE-U es un proyecto académico de Desarrollo de Software de la Universidad de San Buenaventura. Su objetivo es facilitar la conexión entre egresados y empresas mediante perfiles profesionales, ofertas laborales y postulaciones.

Este repositorio es un fork del [repositorio original del equipo](https://github.com/pipemartinez20/Portafolio-hire-u). El [portafolio publicado por el grupo](https://pipemartinez20.github.io/Portafolio-hire-u/) corresponde a ese repositorio.

## Qué incluye este repositorio

- [Portada del portafolio](index.html) con el alcance del proyecto, sus entregables, el resumen de planeación y el equipo.
- [Hoja de estilos](styles.css) con el diseño adaptable de la portada.
- [Manual de instrucciones](manual%20de%20instrucciones/index.html) con la navegación del portafolio y el flujo previsto de la plataforma.
- [Acta de presentación](01-acta-presentacion.pdf), [plan de gestión y EDT](plan%20de%20gestion%20y%20EDT.pdf), [matriz RACI y diagrama PERT](Matriz%20RACI%20PERT%20Hire-U.pdf), [presupuesto](HIRE_U_Presupuesto_Inversion.xlsx), [matriz de Eisenhower](HIRE-U_Matriz_de_Eisenhower.xlsx) y [análisis PESTEL](HIRE-U_Matrices_PESTEL_Partes.xlsx).

## Cómo abrir el portafolio

1. Clona este fork con `git clone https://github.com/Sebas08888/Portafolio-hire-u.git` o descarga el ZIP desde **Code → Download ZIP**.
2. Abre `index.html` en un navegador. También puedes abrir la carpeta en Visual Studio Code y usar un servidor local como Live Server.

## Alcance de la versión publicada

GitHub Pages sirve el portafolio estático. Desde la página puedes consultar y descargar documentos. El manual describe el flujo previsto de registro, inicio de sesión, perfil, consulta de ofertas y postulación. Esos pasos requieren un entorno con los módulos correspondientes. Los componentes Java y los scripts MySQL se trabajan por separado y no forman parte de este repositorio.

El plan de gestión enumera 12 actividades y estima un presupuesto de $8.250.000 COP. El PERT del taller representa ocho actividades y calcula una ruta crítica de 14 días (A → B → D → F → G → H). Cada documento usa su propio nivel de detalle.
